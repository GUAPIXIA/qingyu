# 更新日志

## [0.3.0] - 2026-09-01（配合 PC 0.17.0 / Relay 0.1.0）

### 新增

- 配对页新增局域网与服务器两张独立连接卡，支持 Relay 二维码、8 位连接码和 PC 审批等待。
- Relay HTTPS/WSS URL 统一策略、Access/Refresh Token 分键加密存储、单飞刷新和缓存状态模型。

### 变更

- 服务器连接地址默认预填 `https://cjbtj.xyz`，仍可按部署环境修改。
- 翻译成功后直接以译文替代原消息正文，避免译文与原文重复显示。

### 修复

- 翻译请求执行期间显示加载状态，避免用户无法判断操作是否生效。

### 兼容

- `ServerConnection` 新增字段全部带默认值，0.2.x 及更早的局域网配对记录无需重新配对。

## [0.2.0] - 2026-08-31（配合 PC 0.16.8）

### 新增

- **可操作的连接错误提示**：配对失败会区分断网、连接超时、端口不可达、DNS、TLS、错误服务、配对码失效、PC 审批超时与请求过频，并直接提示检查同一 Wi-Fi、端口、AP 隔离或按 PC 端指引检查 Windows 防火墙
- **多端点自动回退**：新版二维码包含多个局域网地址时依次探测，自动选择第一个可用地址，避免 VPN、虚拟网卡或多网卡地址排在前面导致真机无法连接

### 变更

- **移动端版本独立**：Android 版本调整为 0.2.0 / build 8，不再跟随 PC 版本号；PC 0.16.8 继续保持协议兼容
- **对话界面紧凑化**：消息时间与翻译、朗读、复制、编辑、重新生成、删除合并到同一行；收紧顶部工具栏、消息间距与底部输入区，“续写 / 润色”位置重新调整
- **会话名称更明确**：全局会话页统一显示“角色名-对话名”，例如“花藕子-新对话 2”；消息摘要不再重复角色名
- **回到最新按钮弱化**：改为更淡的半透明样式，减少对正文的遮挡和视觉干扰

### 修复

- **浏览器可访问但 App 无法连接**：兼容性探测改在 IO 线程执行，修复同步 HTTP 请求触发 `NetworkOnMainThreadException`、导致请求尚未进入配对阶段就失败的问题
- **用户消息短暂消失**：修复用户发送的消息在 AI 回复到达后从当前页面消失、必须重新打开会话才显示的问题
- **顶部状态栏重叠**：自定义顶栏增加系统状态栏安全区，时间、信号、电量与应用标题、连接状态、功能按钮不再互相覆盖
- **软键盘输入布局**：edge-to-edge 窗口中的聊天底栏明确消费 IME inset，并保留 `adjustResize` 兼容旧系统；真机输入时输入框随键盘上移并固定在键盘上方
- **配对稳定性**：兼容性探测保留具体失败原因，二维码首个地址不可达时继续尝试后续地址

## [0.16.6] - 2026-08-29（与 PC 0.16.6 对齐）

> ⚠️ **历史注记**：本节版本号为「与 PC 联动发版」时期的误用，**不属于 Android 独立版本线**。
> 独立版本时间线：`0.1.x` → `0.1.3` → **`0.2.0`（2026-08-31 起独立）** → `0.3.0`。
> 本节内容仍有效（能力与修复描述），但版本号请勿与 `libs.versions.toml` 的 `appVersionName` 混读。

### 新增

- **已配对启动直达**：已配对的设备冷启动直接进入会话区，不再闪现配对页；活跃 PC 丢失时进入设备选择页供手动选择（不自动代选），配对令牌损坏时提示“需要修复连接”且不删除任何数据
- **通知点击直达**：点“生成完成/长记忆”通知回到对应会话，点“连接失效”通知直接前往配对页；启动决策未完成（如首次进入选择设备）时不会误跳
- **连接诊断卡片**：设置页可查看最近连接尝试记录（成功/失败原因与耗时），便于排查内网穿透与断连问题

### 变更

- **连接稳定性重构**：连接决策统一由协调器管理——断网自动探测恢复、断线指数退避重连（0–30 秒随机抖动）、候选地址并发探测并优先上次成功的 PC；REST/WS/图片/朗读共享同一网络栈，多 PC 快速切换不再串台
- **设置同步 v2**：与新版 PC 配对后，设置页修改逐行显示“保存中/已同步/失败重试/与 PC 冲突”，支持“仅本机”分组与滑块合并保存；旧版 PC 自动降级为直接保存并提示
- **配对二维码升级**：扫码兼容新版 PC 的 v2 二维码（一次性配对码 + 有效期，更安全），旧版二维码仍可正常扫描
- **端点与安全规范**：手动输入的地址统一规范化（IPv6 自动加方括号等），公网地址拒绝明文 HTTP，跨主机重定向自动剥离登录凭证
- **通知权限改为用时申请**：不再启动即弹通知权限；开启“任务通知”开关时先说明用途再申请，永久拒绝可一键前往系统设置，首次后台生成给一次性提示
- **版本与 PC 单源对齐**：版本号随 PC 端统一管理（0.16.6 / build 7），更新覆盖安装不再受旧版本号影响

### 修复

- **主题选择**：主题/字体/间距选择面板可正常选中并立即生效，重启后保持所选主题（此前选择无效）

## [0.1.2] - 2026-08-15

### 检查更新（从公告服务器获取最新版本号）

- **设置页「关于」新增「检查更新」**：点击后从公告服务器获取最新版本号（走 PC 桥接层 `/api/v1/version` 转发），展示最新版本、更新日志与下载链接
- **多端版本字段支持**：服务器 `/api/version` 新增安卓端字段（`androidVersion` / `androidChangelog` / `androidDownloadUrl`），管理后台可独立配置安卓端版本；安卓端优先取安卓字段，未配置时回退 PC 端字段（兼容旧服务器）
- **版本信息弹窗**：显示当前版本与服务器最新版本、更新内容（changelog 非空时）、下载按钮（点击用系统浏览器打开 downloadUrl，无链接时提示）
- 获取失败时静默降级（不中断），状态行提示；再次点击可重试

### 配套（PC 桥接层）

- 新增 `GET /api/v1/version` 端点：复用 PC 端 `app:checkVersion` 逻辑（提取 `fetchVersionInfo`），转发公告服务器 `/api/version`，失败返回 null
- 桥接层路由测试新增 version 端点用例（mock 公告模块避免真实网络）

## [0.1.1] - 2026-08-15

### 初版发布：轻语安卓伴侣端（qingyu-companion）

PC 端「轻语」的安卓伴侣端首版：只做远程连接与对话消费，不做本地 AI 对话。完整方案见 `docs/安卓伴侣端方案.md`。

### 配对与连接

- **扫码配对**（ZXing，二维码自动填入）+ 手动输入主机/端口/配对码，替代手抄配对码
- **已配对设备管理**：多 PC 切换 / 移除
- **版本协商**（`/api/v1/server/info`）+ **mDNS 自动发现** `_qingyu._tcp`（点击自动填入主机/端口）
- **401 令牌失效横幅**：PC 吊销/过期令牌时提示重新配对（方案 §6.2）
- 断线指数退避自动重连 + 连接状态栏

### 会话列表

- REST 拉取 + WS `session:updated` 增量刷新
- **离线只读回退**（Room 本地缓存）
- 二次确认删除 + **长按重命名**

### 单聊

- 发消息（`requestId` 幂等、**引用回复 replyToId**）
- 流式接收（`ai:chunk` / `ai:done` / `ai:error`）+ 停止生成
- 历史分页（`beforeId` 游标）+ **chunk 节流批量渲染**（方案 §8 弱网对策）
- 发送中/失败气泡 + 手动重试 + **连接恢复自动重发**（断线队列，复用幂等键）
- 聊天时间线（今天/昨天/MM-dd 日期分隔）+ 消息时间戳与 token 用量展示（`ai:usage` 事件）
- **长按消息操作**：复制 / 编辑 / 删除 / 翻译 / **重新生成** / **朗读** / **引用回复**
- **swipe 候选切换**
- **快捷回复条**（text/preset/command 全类型，点击走 execute 端点，text 降级直发）

### 多模态与朗读

- **图片消息**：URL（桥接层静态路由）走 Coil、base64/data URI 兜底解码，多图两列平铺，点击全屏大图查看（左右滑动）
- **TTS 朗读**：长按「朗读」→ ExoPlayer 拉取 PC 合成音频流边下边播（`Media3`，`TtsPlayer` 接口 + `ExoPlayerTtsPlayer` 实现）
- **心理描写折叠**：`<thought>` / `<thinking>` 块提取（对齐 PC 端 `messagePostProcess.ts` 规范）+ 默认折叠展开

### 渲染与角色

- Markdown 本地渲染
- 角色浏览（Coil 封面）+ **「设为当前角色」**（协议假设端点，PC 落地前失败仅提示）

### 设置与阶段三

- 设置页：**退出时清除全部数据**（二次确认）、**清除本地缓存**（保留连接）、连接管理入口、**内网穿透指引**（方案 §5.2 三路线）、关于/版本
- **用量统计只读页**（`/api/v1/usage/summary`）
- **公告同步页**（`/api/v1/announcements`）
- 消息推送与自建中继方案见 `docs/阶段三方案.md`（设计稿，待评审）

### 工程

- 版本号集中管理：`gradle/libs.versions.toml` `[versions]` 中的 `appVersionName` / `appVersionCode` 为唯一权威来源，`app/build.gradle.kts` 引用（v0.1.1 / build 2）
- 架构分层：`model`（DTO 对齐 `shared/types.ts` + WS 事件领域模型 + 消息合并纯函数）/ `network`（Retrofit + OkHttp + WebSocket + 连接管理 + mDNS）/ `data`（Room 缓存、DataStore 连接存储、仓库、DI 容器）/ `ui`（Compose 页面与组件）
- JVM 单元测试覆盖 Markdown / thought / 消息合并 / 图片源等核心纯函数
