## 新增与归档文档规则

- 必须遵守的流程约定 → `规范/`（发版操作只维护在「项目更新与上传规范」）
- 功能设计、优化计划 → `方案/`（文首标注状态；**落地验证后一律移入 [`方案/归档/`](./方案/归档/README.md)**，`方案/` 只保留未收口文档）

- 过时、被取代或不再维护 → **移入对应分类的 `归档/`**，文首加归档横幅，并在本页与归档 README 登记
- **新建文档命名（2026-09-13 起）**：建议文件名带日期 `…-YYYY-MM-DD.md`（创建或最近重大修订）；**存量文档不追溯改名**
- 状态只使用文首词表四档；禁止自创「仍有效 / 调研参考 / 主要缺陷已修」等未登记措辞
