## 归档规则

1. **不再直接删除文档。** 文档过时或被取代后，一律**移动**到本目录，保留原文件名。
2. 移动时必须同步登记两处：
   - 本页下方「归档清单」表格（移除日期 / 原分类 / 移除原因 / 取代者）；
   - [`../README.md`](../README.md) 的「已移除/」小节。
3. 文件名冲突时，在原文件名后追加移除日期：`原文件名-YYYY-MM-DD.md`。
4. 归档文件**不再更新内容**，仅作历史留档。文内引用的路径、版本号与代码位置可能已经失效，阅读时以仓库当前状态为准。
5. 需要恢复时，从本目录移回对应分类目录（`规范/` / `方案/` / `报告/`），并从本页清单中删除该行。
