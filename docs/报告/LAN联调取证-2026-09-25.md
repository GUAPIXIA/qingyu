## 流程与结果

| 步骤 | 断言 | 结果 |
|---|---|---|
| PC `startAuthWindow` | QR 含 scope=sync、host/port、TTL | ✅ |
| 客户端 `parseLanSyncQr` | 解析成功、端点/scope 正确 | ✅ |
| 客户端本地 ECDH + `deriveShortAuthString` | 与 PC `submitPeerHello` 回传 SAS **一致** | ✅ |
| `POST /sync/v1/auth/hello` | 200，登记 MuMu-Android | ✅ |
| PC `confirmPeer(正确 SAS)` | phase=confirmed | ✅ |
| `GET /auth/status` | confirmed=true | ✅ |
| 会话密钥 `deriveLanSessionKeys` | 客户端 vs PC `takeSessionKeys` **一致** | ✅ |
| `POST /session` | 建同步会话 | ✅ |
| `POST .../push` + 同 batch 重放 | 第二次 `idempotent=true` | ✅ |
| `POST .../prepare` | staging→prepared | ✅ |
| `POST .../commit` | 200，写 head + receipt | ✅ |
| `GET .../receipt/:batchId` | 响应丢失可恢复 | ✅ |
| `revoke` 后再建 session | 503 `sync_dormant` | ✅ |
| SAS 不一致 `confirmPeer` | `short_auth_mismatch` 拒绝 | ✅ |

## 边界

- 本取证在 **同一主机 HTTP** 上验证协议与鉴权语义；**MuMu ↔ PC 跨进程/跨网卡** 真扫码联调仍需 PC 开授权窗出二维码 + 手机扫码（或后续把 QR 注入 `SyncAuthViewModel`）。
- commit 依赖 PC 同步域（`syncDomainService`）；未挂域时返回 503 `sync_domain_unavailable`（与休眠门区分）。
