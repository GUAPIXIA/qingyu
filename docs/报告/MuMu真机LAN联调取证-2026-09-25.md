# MuMu ↔ PC 真 LAN 联调取证（QR 注入，2026-09-25）

> 脚本：`scripts/lan-hold.ts`（+ `scripts/lan-mumu-e2e.ts` 编排）  
> 运行：`pnpm exec tsx --import ./scripts/electron-stub.mjs scripts/lan-hold.ts`  
> 报告：`output/pce01/lan-mumu-report.json`

## 链路

```text
PC /sync/v1 + LAN 授权窗
  → QR(host=127.0.0.1:port)
  → adb reverse tcp:port
  → am start --es sync_qr_b64（注入，与扫码同一 onQrScanned 路径）
  → Android ECDH + 本地 SAS
  → POST auth/hello
  → PC confirmPeer（同 SAS）
  → Android poll status → Confirmed → openSyncSession
  → push / prepare / commit
```

## 实测（2026-09-25 12:30）

| 步骤 | 结果 |
|---|---|
| QR 注入（`SyncQrInject` → `onQrScanned`） | ✅ 进入「正在连接 PC…」 |

## 代码入口（Android）

- `MainActivity.EXTRA_SYNC_QR` / `EXTRA_SYNC_QR_B64` → `SyncQrInject.submit`
- `SyncAuthScreen` 消费 pending → `vm.onQrScanned`（与扫码相同）
- `CompanionNavHost` 收到注入自动进入 `Routes.SYNC_AUTH`

## 环境要点

1. **必须用 `adb reverse`**：MuMu（10.0.2.15）无到宿主默认路由，`10.0.2.2`/宿主 IP 均超时。  
2. **`adb install` 会清掉 reverse**：先装 APK，再 `reverse`，或跑联调时 `LAN_INSTALL_APK=0`（默认跳过安装）。  
3. `scripts/electron-stub.mjs` 提供 electron ESM 桩，供 tsx 跑 PC 侧路由。
