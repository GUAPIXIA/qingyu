## 3. 实机抓到并已修的 P0

**打开同步中心崩溃**

```
java.lang.RuntimeException: Cannot create an instance of class
  com.qingyu.companion.ui.sync.SyncCenterViewModel
Caused by: NoSuchMethodException: SyncCenterViewModel.<init> []
```

原因：`viewModel()` 默认工厂需要无参构造，而 `SyncCenterViewModel(store, …)` 带参。  
修复：`SyncCenterScreen` 改为 `LocalAppContainer` + `viewModelFactory { initializer { … } }`（与 SettingsScreen 同模式）。  
复验：再次打开同步中心/局域网页正常；instrumentation 61/61 仍绿。
