# PC 端动态上下文 W10 设置、预设迁移与诊断实施报告

> 日期：2026-09-14  
> 对应方案：[PC 端动态上下文与生成规划器重构实施方案 §7.12](../方案/PC端动态上下文与生成规划器重构实施方案-2026-09-13.md)  
> 状态：已实施，等待随版本进行真实端点体验验收

## 1. 交付结论

W10 已完成设置、预设兼容迁移和脱敏诊断三部分接线：

1. 快捷设置提供默认回复长度；设置页“生成规划”保留思考强度、连续性保护、自动补全结尾和费用提醒，高级层提供端点输入/输出能力覆盖、能力来源与置信度、门控探测、分类用量和最后一轮计划/实际对照。
2. `settings` 唯一迁移链由 v3 升到 v4；迁移只在主进程执行，不新增 renderer 写回路径。
3. `maxTokens = 0` 继续表示自动，任意用户正数继续作为严格输出硬上限；旧内置预设的快捷值只补篇幅偏好，用户保存或导入的旧预设不会被误判为篇幅意图。
4. 旧 `maxContext` 只能收紧内置能力；只有用户在当前连接上明确启用能力覆盖，才允许高于内置值。覆盖已接入单聊、群聊、Bridge、降档恢复、压缩、长记忆和方向生成。
5. 世界书固定比例退出生产分配：旧值只进入 `generationMigrationV4.legacyLorebookRatio` 迁移记录，设置界面改为说明动态统一分配。
6. 通用 `MAX_REQUEST_OUTPUT_TOKENS = 8192` 安全阀和 legacy 生成管线均保留。

## 2. 设置与运行时语义

### 2.1 默认层

- 回复长度：移到对话快捷设置，提供 `auto / brief / balanced / detailed`；优先级为本轮用户明确要求 > 会话 > 预设 > 全局默认 > 自动。快捷设置不再提供最大 Token 编辑，硬上限集中在预设高级参数。
- 思考强度：`auto / off / low / standard / full`；默认自动。端点不接受对应参数时沿既有保守降级和熔断规则处理。
- 连续性保护：作为生成契约常开，不提供会改变历史或记忆的开关。
- 自动补全结尾：关闭后不再发起尾部修复请求，已有稳定边界收束仍保留。
- 费用提醒：高预算时在快捷设置显示申请上限提示；低硬上限的安全校验不随提醒开关关闭。

2026-09-14 UI 收敛：删除快捷设置中重复且只读的“采样参数”区、最大 Token 快捷档位/输入框和预设摘要中的最大 Token；预设摘要只保留温度、Top P 与预设篇幅，并移除快捷设置中的完整端点展示。行为设置不再为正常用户显示无操作价值的“新版管线”说明卡，仅在检测到旧版数据时显示一次性“切回新版”恢复入口。

### 2.2 高级层

- 能力覆盖按连接保存 `{ enabled, contextLimit?, outputLimit? }`，未明确启用时完全忽略数值。
- 输出能力覆盖仍受 8192 通用安全阀约束；预设正数硬上限继续取更小值。
- 诊断按 `provider + endpointFingerprint + model + task + gate` 聚合，展示输入/输出能力、匹配来源、置信度、门控探测、P90/P95、推理挤占率和最后一轮计划/实际。
- “重置探测”只清除当前端点与模型的门控探测记录，不清除聊天、设置或观测文件。

## 3. v3 → v4 迁移

迁移是确定性、幂等的：不写时间戳、不生成随机值，只补缺失字段。

| 旧数据 | v4 结果 |
|---|---|
| 缺少生成偏好 | 补 `defaultResponseLength=auto`、`reasoningEffort=auto`、自动补尾与费用提醒默认开启 |
| `connectionProfiles[].maxContext` | 原值保留；同时记录到 `generationMigrationV4.legacyProfileMaxContexts`，新增能力覆盖默认为关闭 |
| `lorebookRatio` | 从生产设置移除并记录为 `generationMigrationV4.legacyLorebookRatio` |
| 已有合法新字段 | 原样保留，不被默认值覆盖 |
| 重复执行迁移 | 第一次升级到 schema v4；后续读取不产生额外写入或数据漂移 |

关闭能力覆盖后仍可读取旧 `maxContext`，但它只作为保守收紧值，不构成放大端点能力的授权。

## 4. 诊断隐私边界

renderer 只接收枚举、时间、计数和聚合数值。IPC 返回不包含：

- API Key；
- 完整端点或端点指纹；
- requestId、角色/会话标识；
- 提示词、回复正文、尾部采样；
- 诊断文件路径或原始 JSONL 行。

最后一轮对照只包含请求上限、正文/推理计划 token、正文/推理实际 token（上游不可得时为“未知”）、可见字符数、调用次数和结构化终止分类。

## 6. 保留项

1. legacy 退出仍受 G2 门槛约束，W10 不删除旧链路。
2. 8192 上限是否调整仍由方案第 10 节的独立决策门处理。
3. 真实私有端点的能力覆盖、探测展示和费用文案需随版本做一次人工体验验收；自动化测试使用脱敏夹具，不调用真实模型。
