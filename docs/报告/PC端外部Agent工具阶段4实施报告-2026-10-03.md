## 4. 登记口径（为什么大量 pending 是诚实的）

`pending` 不是“跳过”，而是**已确认登记、并写明需要什么环境**：

| 环境要求 | 代表动作 | 说明 |
|---|---|---|
| `native-dialog` | 字体选择、备份导出/导入、角色/世界书/预设导入导出、图片选择 | 返回 `needs_interaction`，给出交互路径，任务可恢复 |
| `network` | 更新检查/下载/安装、公告、MCP 服务连接与调用、局域网配对、同步冲突处理 | 返回 `blocked` + 环境原因 |
| `model` | 生图、TTS、向量索引/检索、事实向量化 | 返回 `blocked` + 环境原因 |
| 高影响动作 | `updater.install`、`bridge.wipeAll`、`settings.importBackup`、`syncCenter.resolveConflict` | 按方案 §8 需用户授权；本轮不执行 |
