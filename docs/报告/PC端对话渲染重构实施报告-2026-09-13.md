## 2. 根因

1. 引号规则在解析层与 remark 层分叉，且字符集不全。
2. 缺少「流式 vs 终态」解析阶段模型，未闭合对白无法稳定为 `dialogue`。
3. blocks 渲染只做分块，未接入安全行内 Markdown。
4. 双端组件未抽公共渲染器。
5. 消息创建入口未显式 `contentRenderMode`。
6. Zustand 默认订阅整对象引用。
7. 视觉布局用 `<strong>/<em>` 冒充块级容器。

## 4. 架构调整

```
模型流式输出
  → generatedReplyPipeline 清理/终态化
  → Message.content + contentRenderMode='blocks'（新 AI 回复）
  → ChatPage / Virtuoso
  → MessageBubble | GroupChatMessage（仅消息级状态）
  → RoleplayContentRenderer
       ├─ blocks  → parseRoleplayBlocks({phase}) → 语义块 + 行内 Markdown
       └─ markdown / undefined(历史) → ReactMarkdown + remarkRoleplay 兼容
  → src/index.css
```

- 解析层纯函数，单聊/群聊/remark 共用同一引号判断。
- 流式：`complete:false` + `.is-incomplete.is-streaming`；右引号只改 `complete`/正文，不改 `kind`。
- 行内 Markdown：粗体/斜体/删除线/行内代码/链接/换行；无 `rehypeRaw`；`<p>` 不嵌套 `<p>`。
- 开场白：显式 `markdown`；新回复：显式 `blocks`；历史 `undefined`：兼容走 Markdown。
