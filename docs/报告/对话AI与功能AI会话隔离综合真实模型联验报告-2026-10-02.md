## 1. 结果

最终一轮真实网络请求 16 次、检查 39 项，全部通过。初始沿用当前连接「OpenCode Go」及其有效模型 `deepseek-v4.1-flash`；在隔离设置内复制同端点连接档案，切换到端点列出的 `mimo-v2.6-flash`。前者执行 11 次请求，后者执行 5 次。正式用户的设置、凭据、聊天和画板没有被联验修改。

本轮新增可重复执行的 Electron 联验脚本，不修改生产功能代码。沿用阶段 3 的 70 文件、1275 项自动回归结果；新增脚本类型检查、定向 ESLint 和变更空白检查通过。

## 2. 实际覆盖

| 范围 | 真实证据 |
|---|---|
| 正文、画板、翻译并发 | 实际适配器的请求时间重叠；正文正常结束，译文独立提交，画板确认前不改变正式位置 |
| 连续画板指令 | 从茶馆移到渡口，再用“把她移回之前的茶馆”；独立助手历史保留，确认后按实际空间数据核对起点与终点 |
| 任务提示隔离 | 正文包含测试角色身份标记，只读取空间位置；翻译、记忆和润色不包含完整角色提示或画板控制材料 |
| 独立取消与后台记忆 | 翻译收到真实流式片段后取消；并行正文和自动记忆任务仍成功，半截译文没有保存 |
| 过期结果 | 翻译发出后修改原消息，真实完成结果被提交端拒绝；润色期间推进编辑版本，结果保留为旧建议 |
| 配置切换 | 旧位置查询已经进入真实适配器且尚未结束时切换配置；它继续使用旧模型，生产剧情队列随后使用新模型和新 profile ID |
| 已提交状态回读 | 新模型的明确移动提案确认后，下一轮正文请求读取渡口的只读位置块 |
| 单聊／群聊／会话归属 | 相同角色及相同消息 ID 的群聊翻译只更新群消息；另一单聊会话的正文与助手历史为空 |
| 导出与恢复 | 普通 JSON 导出不带功能元数据；真实 ZIP 保留正式位置、已提交记忆和群聊译文；恢复时取消真实在途翻译，同 ID 的旧任务不能迟到提交 |
| 用量和凭据 | 每次真实请求均与持久化观测中的实际模型及任务类型一致；公开功能历史不包含密钥或完整端点；复制的设置、凭据和 Local State 已清理，源配置文件哈希未变 |

## 4. 验收边界与诊断

联验加载真实 Electron 服务、生产上下文、适配器、功能任务管理、提交、记忆、画板队列和备份代码；本地事件桥接替代窗口通信，并驱动这些真实入口。模型响应来自实际网络，文件和 ZIP 为真实隔离数据。本轮不是浏览器界面或真实 preload 通信验收；界面与群聊六种发言／叙事组合沿用先前阶段的自动、浏览器及专项模型证据。

执行过程中先发现测试夹具遗漏 `spatialBoardEnabled`，在发出网络请求前被服务拒绝；随后发现测试翻译语言与设置不符，提交端正确拒绝。补齐测试设置，并从保存后读取消息建立来源，没有调整生产校验规则。失败执行不计入最终 16 次请求；此前真实请求也可能产生供应商用量。

新模型提取的证据是“林雪已经离开茶馆，走到青石城的渡口内。”。既有完成动作校验对包含“离开”的整段证据采取保守拒绝，保存诊断且不移动人物。这意味着此类混合表述可能需要用户通过明确画板指令调整。联验保留该边界，随后验证明确移动指令及确认，不将不具备资格的候选强制应用。

本轮不扩展单会话复制／聊天记录导入入口，不实施其他客户端。标题、方向、压缩、更多编辑页面、删除和重启边界沿用先前自动回归；不将它们写成这轮真实模型覆盖项。
