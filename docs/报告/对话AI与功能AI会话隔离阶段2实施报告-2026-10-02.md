## 1. 实施结果

翻译、方向、标题、记忆和压缩沿用阶段 0 的有效聊天配置解析，分别维护请求、监听、结果与取消。单聊使用 `single + characterId + sessionId`，群聊使用 `group + groupId + sessionId`；消息任务还关联具体消息，翻译另区分目标语言。内部重试保留连接和任务快照，手动重试重新创建任务。

新增 `shared/featureSource.ts` 定义 owner、消息版本引用和提交协议。来源引用包含消息 ID、正文指纹、Swipe、生成身份、发言身份及必要的会话字段；群聊方向和记忆还核对成员名单与发言模式。指纹用于检测版本变化，不作为安全签名。

主进程在消息锁、会话锁内核对来源、取消事实及目标是否存在，只修改对应业务字段。旧结果不能通过保存整条消息覆盖新正文、图片、检查点或其他辅助字段，也不能重建已删除的消息和会话。重复提交使用任务 ID 收口。

| 功能 | 本阶段行为 |
|---|---|
| 单聊／群聊翻译 | 冻结 owner、原文、消息版本与目标语言；提交端再次核对语言；空结果、不完整结果和旧结果不写入。编辑、删除、重生成和 Swipe 取消对应消息任务。缓存显示核对来源与语言。 |
| 单聊／群聊方向 | 使用专用方向提示和最近材料，移除角色预设 jailbreak；同名消息 ID 在不同 owner 中独立去重与取消；有界重试沿用快照。新用户消息取消本会话在途方向，即使还没有任何已完成候选。失效的已保存候选不再展示。 |
| 自动标题 | 使用专用标题提示；提交核对默认标题、来源和手动改名修订号。手动改名再改回默认名称也不会接受旧自动标题。失败保留原标题与可重试状态。 |
| 单聊／群聊记忆 | 保留增量窗口、事实解析和 memoryVersion 提交规则，并增加消息范围、会话身份及任务引用校验。范围包含被模型输入略过的空消息／系统消息，避免两端校验口径不一致。单聊来源正文变化和会话删除可取消运行请求；群聊请求有独立取消与空闲超时。旧会话错误及列表刷新不覆盖新页面。 |
| 历史压缩 | 在裁剪历史时冻结来源，而非回复结束后重新为旧材料签名。提交核对范围正文和原压缩版本；读取摘要时再次验证来源。移除 20000 字静默截断，超输入预算时保留原文并跳过本次压缩。 |
| 世界书压缩 | 按 owner 和已有条目来源 key 独立请求；走相同任务监听、取消和用量路径。主进程按 key 原子合并缓存，避免晚到结果读取另一群聊的缓存再整份覆盖。来源 key 继续沿用已有条目修订与预算规则。 |

一次性结果继续存于消息／会话现有数据域，新增必要的来源引用和任务身份。运行态保留在内存，公开引用不包含 API Key。页面切换只改变展示，结果仍按冻结 owner 提交；删除和清空取消所属任务。辅助任务的取消与失败不改变主回复终态。

## 2. 请求与兼容处理

渲染层公共任务运行器提供请求级事件过滤、60 秒空闲超时、监听清理及取消；单聊主进程记忆提供独立 AbortSignal 和 120 秒请求上限。取消后可建立新任务，旧任务收尾不会删除新任务的去重记录。主进程保留短期取消事实，模型响应已完成但提交仍在等待写锁时也可拒绝取消任务。

OpenCode 的 OpenAI、Claude、Gemini 三种适配路径按功能逻辑会话／任务生成独立路由头。主聊天路由保持原规则，功能内部物理重试保持同一功能路由；旧辅助调用也使用独立请求路由。仅向原适配器限定的官方主机发送该头。

统一了旧消息默认 Swipe 0 和发言身份的指纹计算。补测发现群聊点名回复的界面时间戳与落盘时间戳不同，完成后的生成身份也未同步到界面；已对齐正常收尾及中断保存的消息来源，避免刚保存的回复被辅助任务误判为过期。

既有无来源引用的历史压缩摘要保留存储字段，但不再注入 PC 模型上下文，后续有效压缩可替换它。旧已完成译文和方向保留兼容显示；新结果按来源核对。独立的跨客户端群聊装配 oracle 与 Android golden 契约保持原状，其他客户端接入另行实施。
