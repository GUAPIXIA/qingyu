## 1. 执行方式（与备忘录一致）

```powershell
$env:GRADLE_USER_HOME="D:\Code\gradle-home"
$env:ANDROID_HOME="D:\Code\android-sdk"; $env:ANDROID_SDK_ROOT="D:\Code\android-sdk"
$env:ANDROID_AVD_HOME="D:\Code\android-avd"

# 逐台串行（禁止三开）；每台前 taskkill qemu-system-x86_64-headless.exe
emulator.exe -avd qingyu-api26 -no-window -no-audio -no-boot-anim -gpu swiftshader_indirect -port 5554
# 等 sys.boot_completed=1，核对 ro.build.version.sdk == 目标档
$env:ANDROID_SERIAL="emulator-5554"
.\gradlew.bat :app:connectedDebugAndroidTest --rerun --console=plain
```

| 检查点 | 本轮记录 |
|---|---|
| 开跑前 QEMU 残留 | 0 |
| D 盘可用 | ~59 GB |
| 每台 `ro.build.version.sdk` | 26 / 31 / 34（逐台确认，防串台） |
| `--rerun` | 每台均加，避免缓存回放假绿 |
| 杀进程 | `qemu-system-x86_64-headless.exe` + `emulator.exe` |

**GMD 路径**：按备忘录，api31 托管设备仍会踩 adb 2min 超时，**本轮不走 GMD**，只走经典 AVD。
