# 空间画板 PC 实机问题修复报告

日期：2026-10-03。前次实机测试报告中的两项问题已修复，并通过本机 Electron 和真实模型复验。

## 修复结果

1. **单聊模型复述旧起点**：位置快照正确写入并发出，但结构化路径之后的长规则没有稳定压过旧开场。诊断证明，在空间块末尾再次用自然语言明确当前位置可以纠正原失败请求。现在根据真实 world/runtime 生成该尾注，保留全部知情范围、用户主权和只读规则；最低必需块和包含补充关系的完整块都以该尾注结束，并计入原有 800 token 预算。未放置、未知精度、未登记或明确不参与的角色使用对应事实，不推断为在场。
2. **小窗口裁切开关**：嵌入画板在宽度不超过 560px 时收紧顶栏间距，让世界名称弹性占用剩余空间，隐藏开关旁的重复文字。开关的无障碍名称保持“启用空间画布”，返回、名称、助手及开关全部保留。真实 900×600 群聊窗口、两侧栏展开时，开关从原 x=904.56–940.56 移到 x=840–876，位于 iframe 的 x=480–884 范围内。
