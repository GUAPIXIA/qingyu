## 1. 使用方式

打开单聊画板的“画板助手”，在原有“剧情同步”下拉框选择 **自动**。默认仍是 **需确认**，可随时切回需确认或关闭。

| 情况 | 处理 |
|---|---|
| 普通新回复，角色已明确到达已有地点，置信度 ≥ 0.9，来源与版本有效 | 自动提交整批位置更新，聊天输入区显示“本轮位置已自动同步”，可查看或撤销 |
| 用户角色（persona）移动 | 仍需确认；即使用户明确声明且置信度高，也不会自动移动用户 |
| 续写或重新生成 | 有效位置候选仍需确认；不合格模型结果按提取失败处理 |
| 低置信度、未知或歧义地点、未完成动作 | 保留确认或诊断入口；未知地点不会自动创建，未完成动作不能确认成移动 |
| 混合人物或含未明确项的批次 | 整批等待核对，不能先移动其中一人 |
| 关闭对话读取位置 | 暂停剧情捕获与同步；独立画板指令和手动编辑仍可使用 |
| 同步模式在发送后发生变化，或位置读取被关开 | 本轮不自动批准；重新开启不会追认旧建议 |
| 版本冲突、来源修改或绑定变化 | 不覆盖当前画板；可核对的版本冲突继续走重新核对与再次确认流程 |

自动应用中的确认入口暂时锁定，策略开关仍可操作。助手显示自动结果或未自动采用的原因，证据与版本按需展开。继续沿用 PC 的现有配色和紧凑侧栏。

对话 AI 只读已经提交的位置关系。画板提取、指令、候选、JSON、确认与撤销记录仍保存在独立助手会话中，连接和模型沿用当前聊天配置。

## 2. 主进程约束

- 发送检查点冻结 `syncPolicy` 与 `syncEpoch`；`spatialNarrativeSyncEpoch` 由主进程在读取/同步开关变化时生成，普通会话 patch 不能注入代次。重复设置相同值不会误使本轮失效。
- 保留每个动作的原始 `confidence`。自动条件要求整批均为当前角色的 `move_actor` / `place_actor`，逐项匹配原候选人物、目标、完成状态与证据资格，不能含 persona、未解析项或重新核对提案。
- 先持久化自动决定，再通过与手动确认相同的 `spatialService.applyEditorBatch` 写入。提交前再次读取策略、来源、身份、助手归属、绑定与版本，并核对原任务的运行身份。
- runtime、world、sidecar、助手自动结果和提交收据同属空间事务。已提交后写入中断时，恢复实际应用结果；不能显示需确认后再次移动。
- 未提交的自动决定在重启后转为手动确认，不重复自动尝试、不补发模型请求。恢复备份会取消旧任务，旧自动任务不能写入恢复后的同 ID 助手。
- 自动更新复用阶段 3 的逆命令撤销和版本保护。后续有其他修改时拒绝撤销覆盖；重复通知、确认、恢复与撤销保持幂等。

## 3. 真实模型发现与修复

使用当前配置的 **小米 / `mimo-v2.6-flash`**，在隔离 userData 中调用实际模型，正文材料受控，提取与提交走正式持久队列和主进程服务。没有修改用户的聊天、地图或连接配置；测试结束后清除隔离目录中的配置凭据和 `Local State`。

首次验证发现模型把“我仍在花园”附加为新的位置说明，旧解析器将同地点说明变化视为移动，导致原本只有角色移动的自动批次变成 persona 混合批次。现已按地点关系过滤同地点的说明变化，并明确提示重复声明原位置不算移动。

另有前序请求返回同一人物同时出现在 `changes` / `unresolved`，或省略 `evidenceSource`。主进程均拒绝结果，位置未变化。补充提示说明发送前位置基线、根画板场景名称、人物候选唯一性和八个必填字段；保留严格校验，不补造缺失证据，也不自动重试请求。

最终阶段 4 的 **7 次新增真实提取全部完成**：

| 场景 | 模型结果 | 实际处理 |
|---|---|---|
| 普通角色移动 | 置信度 0.95 | 自动应用；用户保持原位；下一轮主对话读到新关系 |
| 用户明确声明移动 | 置信度 0.97 | persona 提案仍需确认 |
| 重新生成 | 置信度 0.8 | 需确认，不移动 |
| 续写 | 置信度 0.9 | 需确认，不移动 |
| 切回需确认 | 置信度 0.85 | 普通待确认提案 |
| 发送后开启自动 | 置信度 0.95 | 发送时策略阻止事后批准 |
| 未知钟楼 | 未解析目标 | 保留核对，不创建或移动 |

最终报告 **97 项检查通过**，复用先前已通过的阶段 0—3 基线，随后在同一隔离数据中完成阶段 4、自动撤销、ZIP 恢复、幂等和读取暂停补验。报告累计 **21 次完成的模型请求**包含前序尝试及主对话读取探针；其中本次最终增量为上述 7 次。读取暂停补验没有增加模型请求。首次独立实验的 9 次请求保存在单独的初始报告中。
