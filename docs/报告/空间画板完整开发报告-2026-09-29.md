## 1. 项目目标

用可视化画板描述**区域、地点、层级、距离和角色位置**，以结构化数据驱动剧情中的角色移动；任何不具备图片识别能力的 LLM 也能完整理解空间状态。

核心原则：

1. **数据是唯一事实来源**（JSON，非截图/像素）。
2. **布局坐标 ≠ 世界语义**（真实距离只认 distance 关系）。
3. **定义与运行状态分离**（WorldDefinition / WorldRuntimeState）。
4. **所有变更经 SpatialCommand** 进入纯函数 reducer。
5. **不确定时保持原位**（剧情默认 `suggest`，不静默改位）。

## 4. 数据契约（v1）

### 4.1 世界定义 `SpatialWorldDocumentV1`

| 字段 | 说明 |
|---|---|
| `boards[]` | 画板；根画板 `parentEntryNodeId=null` |
| `nodes[]` | **仅** `region`（矩形）/ `place`（地点）两类 |
| `distances[]` | 同类、同画板、无向距离关系 |
| `actors[]` | 角色定义（非第三种空间图形） |
| `geometry` | 无边界 React Flow 画布坐标；允许负数和超出初始视区，所有值必须有限 |

### 4.2 运行状态 `SpatialRuntimeStateV1`

| 字段 | 说明 |
|---|---|
| `placements[]` | 角色位置 + `containmentPath`（核心重算） |
| `events[]` | 移动审计（最近 500 条） |
| `revision` | 乐观并发；剧情命令带 `expectedRevision` |

### 4.3 命令 `SpatialCommand`

`create/update/delete_node` · `create/update/delete_distance` · `create/update/delete_actor` · `place/move/remove_actor`  
批处理原子：任一失败整批不提交；成功后 `revision+1` 并写事件。

## 6. 交互与 UI 能力

### 6.1 画板

- 工具：**矩形区域**（拖拽绘制）、**地点**（单击）、**距离模式**、选择
- 无限平面、缩放 25%–200%、平移、小地图、适应视图、Delete / `Ctrl+Z` / `Ctrl+Y`
- 双击有内部画板的节点进入；面包屑回退
- 主题对齐 PC **tavern** 深色（琥珀金强调色）

### 6.2 属性检查器

- 名称 / 描述 / 分类 / 标签 / 几何（面板显示 1 位小数）
- 距离：数值、单位、精确/估算/未知、显示文本、旅行备注
- 角色：完整路径、相对方位、精度、备注、移出画板

### 6.3 角色

- 托盘添加用户/角色；拖到画布；未放置可一键放下
- 拖动命中：地点 → `inside-only`；区域 → `approximate`；空白 → 画板
- 普通区域中的角色保留落点坐标，可在区域内随意摆放；移动区域时角色随内容实时移动
- 新世界自动创建“未参与对话”区域；其中角色在托盘、属性面板和无图文本投影中均标记为不参与当前对话
- 锚定地点后，地点卡片向右扩展出内部角色槽，头像完全位于地点边框内；同一地点最多显示 3 个头像，其余以 `+N` 聚合
- 地点内无角色时自动收回基础宽度；停靠/区域头像悬停或选中时显示名称；拖回空地恢复完整角色卡片
- 祖先徽标「N 人」：区域内（含子画板）角色数

### 6.4 剧情模拟面板

- 粘贴 `SpatialCommandBatch` JSON
- 策略：`off` / `suggest`（默认）/ `auto`
- 待确认队列：采用 / 忽略

## 7. 剧情安全（§10）

| 情况 | 行为 |
|---|---|
| `off` | 不解析、不移动 |
| `suggest` | 进待确认，不自动改位 |
| `auto` + 完成事实 + 置信 ≥ 0.9 | 直接应用 |
| revision 过期 | **不覆盖**用户拖动，进待确认 |
| 未完成语气（可能/准备/如果…） | 仅建议 |
| 剧情创建/改地图实体 | 直接拒绝 |
| 同一回复冲突移动 | 直接拒绝 |
| 目标不存在/跨画板 | 直接拒绝 |

采用建议时以当前 revision 重提，并放宽 `from` 守卫（用户已确认意图）。

## 8. 交互缺陷修复记录（实测反馈）

| 问题 | 根因 | 修复 |
|---|---|---|
| 拖动不流畅/回弹 | 受控节点未接 `onNodesChange` | 本地 RF 状态 + 松手写领域 |
| 样式与 PC 差距大 | 独立色板 | 对齐 `tavern` CSS 变量 |
| 枚举显示英文 | 选项直接绑枚举 | `labels.ts` 中文标签 |
| 几何数值过长 | 未格式化 | 面板显示 1 位小数 |
| 角色拖出后弹回 | 坐标 `0.1` 网格 + `from` 守卫失败 | 3 位精度写入；用户拖动不带守卫 |
| 人数徽标「1」裁切/不一致 | `overflow:hidden` + 仅按锚点 | 徽标移入区内；几何中心补计 |
| 地点在区内拖到右侧 | RF `parentId` 相对坐标 vs 领域绝对坐标 | **去掉 RF 父子**，一律绝对坐标 + zIndex |
| 区域移动不带动内容 | 拖动中只更新被抓住的 RF 区域，内容要到松手后才写回 | 以拖动起点为基准逐帧预览子孙节点与区内角色；松手后单批提交，仍可整体撤销 |
| 地点移动时内部角色延迟跟随 | 实时跟随预览只为区域建立，地点内头像要等松手重投影 | 将预览统一为节点拖动机制；地点拖动逐帧带动直接锚定角色，松手时以同一位移批量提交并支持撤销 |
| 区域角色被吸附到固定位置 | 区域与地点共用停靠投影 | 仅地点使用聚合停靠；区域角色改为 `floating` 投影并保留精确落点，可在区内自由布局 |
| 无法区分未参与当前对话的角色 | 新世界缺少明确的离场语义 | 新世界内置带 `system:offstage` 标签的“未参与对话”区域；角色状态由包含路径计算，并同步到 UI 与紧凑文本投影 |
| 地点图标小、多角色遮挡内容 | 地点与角色卡片占地接近，角色全部以完整卡片高层级叠放 | 地点基础卡片为 `82×82`，图标改为统一线性 SVG；角色进入后向右扩展至 `122px` 并在边框内收纳 `28px` 头像，3 人以上以 `+N` 聚合，无角色时自动收回 |
| 区域靠近旧画布边界时内容偶发掉队 | 领域层把布局坐标限制为 `0..1`，越界批次回滚而 RF 仍保留本地位置 | 移除固定边界，领域、命令、剧情、Schema 与属性面板统一使用任意有限画布坐标 |
| 含子区域的父区域向上拖动偶发失效 | 父级推断把父区域新中心命中的子区域旧位置当作新父级，触发 `cycle_detected` 原子回滚 | 推断移动区域的新父级时排除其完整子孙集合；同级区域仍可正常成为父级 |
| 画布范围不足 | `1200×800` 同时充当换算尺度和硬边界 | 改为 React Flow 原生无限平面；`1200×800` 仅保留为初始参考视区，持久化直接保存 flow units |
| 级联删除遗留悬空引用 | 清理范围只覆盖入口节点 | 按完整删除子树清理距离、角色位置与子画板引用 |
| 删除角色/级联删除无法撤销 | 复合逆命令被 history 再次反转 | 逆命令按实际撤销执行顺序的逆序保存 |
| 导入防护未接 UI | 文件入口直接 `JSON.parse` | 读取前检查 5 MiB，统一走深度/污染键/JSON 防护并捕获错误 |
| 跨世界 runtime 可混入 | 未校验 `runtime.worldId` | 世界 ID 强一致；导入事件裁剪为最近 500 条 |
| 畸形剧情命令抛异常 | 仅做 TypeScript 类型断言 | 解析阶段校验角色、目标画板、锚点与坐标结构 |
| 撤销/重做按钮不刷新 | TopBar 未订阅 history | 订阅 undo/redo 栈深度；撤销后清理失效选择 |
