## 3. 数据验收（§21.2）

- **往返无损**：`city-home` 世界/运行状态 JSON 深比较全等；store 导出→导入→再导出关键字段一致。
- **无图可读**：紧凑文本投影仅依赖 `id/name/description/containmentPath`，不依赖 `avatarAssetRef`。
- **确定性**：相同输入重复投影字节级一致（`core.test.ts`）。
- **引用完整**：悬空 ID、循环父子、跨类型/跨画板距离均被拒绝。

## 4. 性能基线（§16）

| 指标 | 目标 | 实测 |
|---|---|---|
| 300 节点构建 + 500 距离 + 全量校验 + 全图投影 | < 1s | `phase5-quality.test.ts` 通过（单次批处理） |
| 拖动期间不写盘 / 不全量校验 | 设计约束 | 拖动仅更新临时位置，`pointer up` 后才 `update_node` |
| 缩放范围 | 25%–200% | React Flow `minZoom=0.25` / `maxZoom=2` |

> 注：E2E 浏览器帧率未做自动化计分；交互路径为标准 React Flow，节点组件 memo 化。

## 5. 导入防护（§13.3）

| 规则 | 实现 |
|---|---|
| 文件 ≤ 5 MiB | `parseImportJson` |
| 画板 ≤ 200 / 节点 ≤ 5000 / 距离 ≤ 10000 | `guardWorldImport` |
| 层级深度 ≤ 20 | `measureNodeDepth` |
| JSON 嵌套深度 ≤ 64 | 粗扫描防栈溢出 |
| 非法 JSON / 原型污染键 | 拒绝 |
| 循环父子、悬空引用、跨类型距离 | 领域校验拒绝 |
| 运行状态悬空 actor/锚点 | `guardRuntimeImport` |

## 6. 剧情安全（§10）

- 默认 **`suggest`**，绝不静默改位。
- `revision` 过期 → 待确认，不覆盖用户拖动。
- 未完成语气（可能/准备/如果…）→ 仅建议。
- 剧情创建/修改地图实体 → 直接拒绝。
- 同一回复冲突移动 → 拒绝。
- 批原子：任一命令失败整批不提交。

## 7. 隔离验收（§21.3）

- `check:boundary` 扫描全部源文件，**零** `src/` / `electron/` / `shared/` 反向依赖。
- 独立 `package.json` / Vite 端口 **5188**，不进 PC workspace。
- PC 侧无路由、IPC、数据目录改动（`docs/方案/空间画板-PC禁改清单-阶段0.md`）。

## 8. 已知限制

1. **浏览器 E2E**：关键旅程以 Vitest 集成测试覆盖数据与状态机；Playwright 真拖拽 E2E 未纳入 CI（阶段 5 可选增强）。
2. **拖拽区域创建**：子区域落点推断以中心点为准；复杂重叠区域需在属性面板改父级。
3. **`containmentPath` 深度**：> 20 层拒绝导入，但超深子画板链在 UI 面包屑中仅展示有限级。
4. **事件日志**：保留最近 500 条，旧事件直接裁剪，未做归档快照（MVP 允许）。
5. **真实 LLM 接入**：仅模拟 Story Adapter；模型工具协议待 PC 接入评审（阶段 6）。
6. **多人协作 / 云同步**：未实现，按方案属后续扩展。
7. **保存失败**：提示导出 JSON + 延迟重试；未做多级本地备份。
