## 1. 本批交付

群聊页头增加「画板」入口，沿用现有配色和紧凑布局。打开后可创建空白世界、绑定已有世界、绘制区域和地点、放置或移动成员、撤销和重做。群聊正在生成时禁止进入手动画板。

群聊不会复用首位成员的单聊身份。空间归属固定为 `kind=group + groupId + sessionId`；一个群聊会话共用一份位置数据。不同群聊、不同会话以及单聊可共用世界定义，各自的位置独立保存。运行身份由完整群聊和会话 ID 计算稳定哈希，单聊的原目录和协议继续可用。

新增目录：

```text
spatial/group-runtimes/<groupId>/<sessionId>.json
spatial/group-session-state/<groupId>/<sessionId>.json
```

`GroupSession` 增加世界和运行身份绑定，绑定通过专用主进程事务更新，普通会话更新白名单不能改写。四个群聊 IPC 分别负责读取、创建、绑定和命令提交。

## 2. 成员和用户身份

| 变化 | 处理 |
|---|---|
| 首次建图或绑定 | 按群成员角色 ID 和有效 persona ID 建立 actor 映射，不推断人物位置 |
| 加入成员 | 创建缺失映射，默认未放置，已有成员位置保留 |
| 移出成员 | 从当前角色托盘和画布隐藏，保留共享世界定义、历史位置与事件 |
| 角色改名 | 根据稳定角色 ID 更新名称，不新建身份或迁移位置 |
| 改换 persona | 新身份未放置，旧身份的历史位置保留，位置不会继承 |
| persona 为 null | 当前群聊无用户实体 |
| 旧会话缺少 personaId | 使用全局默认 persona；配置和资料变化会刷新已绑定群聊 |
| 删除身份资料 | 旧 actor 和历史位置保留，从当前参与视图退出 |

头像从角色卡和 persona 资料读取，不把头像 URL 写成新的世界定义。群聊中的角色定义由成员设置管理，编辑器隐藏额外角色创建和角色定义删除；位置备注、地点、区域和手动移动继续可编辑。

## 3. 提交、切换和恢复

- 群聊复用命令权威服务，校验绑定 epoch、位置 revision 和世界 fingerprint；跨群聊、跨会话和混合归属拒绝提交。
- 同一个 commit ID 重试返回原收据，不重复应用。非法命令使整批失败，不保存部分位置。
- 世界、运行状态和提交记录进入同一事务。中断恢复只更新空间绑定，保留并发修改的标题、身份和记忆。
- 共享结构保护扫描单聊及群聊位置，拒绝删除或改变仍被会话使用的节点、画板和角色引用。
- 切换群聊、切换/新增/删除会话、保存群设定、改变用户身份以及主导航前等待 iframe flush。保存错误保留原上下文，提供重试和载入最新画板。
- 删除群聊或会话先恢复待完成事务，然后清理其绑定、运行状态及提交记录；共享地图和其他会话的位置保留。
- 完整 ZIP 备份覆盖群聊绑定、位置、提交收据和反向命令。恢复预检拒绝缺失 owner、错配 runtime、缺失提交记录、混合身份和越界事务，写盘前完成校验；合法中断事务支持 before/after 混合文件。

工具栏撤销/重做使用当前编辑器的历史栈。主进程保留提交及反向命令用于一致恢复和去重；本批没有增加跨关闭、跨重启的编辑器撤销历史列表。
