## 1. 本批交付

群聊沿用页头「画板」入口、角色头像和紧凑布局，启用独立画板助手。用户可生成空间草稿，在画板修改，再确认建立正式世界与位置；已绑定画板可接收显式调整指令和未知起点建议，全部先形成待确认提案。

对话请求读取已确认的语义位置，不带画布坐标、画板命令、助手历史或待确认草稿。确认移动后，下一次对话读取新位置。群聊会话提供「对话读取位置」开关；关闭后沿用普通群聊上下文。

没有增加功能连接或模型选择器。画板任务使用所属群聊当前有效连接/模型。修正群聊正文和记忆整理的模型快照，使 `activeModel || profile.model` 同时用于预算、实际请求及用量记录，避免预算与发送模型不一致。

## 2. 发言规则与叙事视角

| 场景 | 实施行为 |
|---|---|
| 点名、轮询 + 沉浸 | 按当前发言者提供自身路径和同地点成员关系，隐藏异地成员路径 |
| 自由发言 + 沉浸 | 提供当前参与者的位置，要求每段只使用该段角色可知的信息，不能转移其他角色的异地知识 |
| 全知叙事 | 提供当前成员的公共位置关系，仍不替用户选择或混淆角色知情范围 |
| 未放置 | 明确为位置未知，不据此判定缺席，不禁止发言 |
| 明确不参与 | 点名/轮询跳过该成员；自由发言保存完整或半截回复时过滤其回应；所有成员均不参与时不调用正文模型 |
| 移出群聊、改换 persona | 退出当前投影，新身份不继承旧位置，历史空间引用保留 |

同群不证明同地；同地不保证视线互通；异地交流需要正文中的电话或消息依据。当前位置优先于设定、旧开场、历史和记忆中的旧位置。只投影语义层级、相对关系和已定义距离，不从像素间距推导真实距离。

空间投影上限为 1600 tokens。相关距离可裁剪并记录；必要位置超过空间或整体输入预算时停止发送并提示，不能悄悄移除已确认位置。渲染端检查群组、会话、发言者、模式和画板绑定，拒绝其他上下文的投影。

## 3. 独立助手与初始化

助手 scope 为 `kind=group + groupId + sessionId + worldId/runtimeId/bindingEpoch`，每个群聊会话保存一份独立功能历史，不映射成首位成员的单聊。共享世界仍各自使用独立 runtime。

初始化材料包括本次说明、最近 12 条非空已保存正文、群聊公共设定、选中成员的场景/描述、有效用户身份及选中的已启用世界书条目。剥离思考文本，不加载角色默认问候或示例对话；来源与角色设定均标明身份。成员场景可勾选，材料裁剪留有标记。

协议支持多位当前成员的正式 actor ID 和有效 persona。不能合并不同住所、假定成员全在同一地点，未知或冲突写入未明确项。证据引用必须来自本次来源，逐字校验；不存在的身份、节点和越界命令被拒绝。起点建议只调整未放置人物。

未绑定初始化保持为助手草稿，不创建正式世界。草稿可通过实际画板编辑，成员映射受群设置管理；用户确认后，修改后的草稿进入正式空间事务。已有空白画板也可初始化，非空画板不被初始化覆盖。

显式移动和初始化确认前重新检查来源 fingerprint、当前成员/身份、助手归属及空间版本。来源或绑定变化使旧提案失效；失效草稿可忽略，不能继续确认或编辑。重复应用返回已有结果，不重复移动。

## 4. 持久化、取消与恢复

`GroupSession` 增加 `spatialAiSessionId` 和 `spatialContextEnabled`。八个群聊专用 IPC 接入只读投影、独立助手读取、来源、请求、取消、忽略、草稿编辑和确认；不复用单聊 owner。

正式确认复用主进程空间事务，将世界、群聊 runtime、提交收据及助手记录一起保存。兼容原有三文件群聊事务，新增四文件事务恢复和归属预检。

取消、成员/身份变化、删除和整库恢复终止在途任务。迟到返回经过任务租约、来源和会话归属复核，不能写入新助手。重启后运行中任务标为中断，未知结果不自动重发模型请求。

ZIP 备份包含未绑定草稿和已绑定助手。恢复预检拒绝跨群聊助手链接、错误绑定及缺失文件，恢复不自动调用模型。删除群聊清理其助手记录和空间数据，保留其他聊天及共享世界。

原生模型联验在隔离用户目录中沿用当前连接：两次真实助手请求完成三位成员初始化及指定成员移动；另外六次使用真实主进程投影和请求适配器，覆盖三种发言规则 × 两种视角的短只读请求，回复采用已确认地点，runtime 未改变。还检查独立会话、成员移除和备份恢复，助手内容未进入正文历史。

这六次短请求未执行完整的群聊 UI 调度、轮询接力或剧情提取。真实渲染端上下文和发送链路由专项测试验证，浏览器覆盖交互；不能将短模型回复作为长剧情中的视角遵守或阶段 2—3 回写已经验收的证明。
