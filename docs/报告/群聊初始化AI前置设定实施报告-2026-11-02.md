## 一、交付摘要

1. **数据与共享逻辑**：`GroupChat.groupPreamble` 可选字段（群级、PC 本地数据）；`shared/groupInitPreamble.ts` 纯函数负责共同场景 / 系统开场的提示词构建、解析、清洗与长度校验；`TextFeature` / `GenerationTask` 新增 `group_init`、`group_opening`，`TASK_BODY_DEFAULTS` 分别为 700 / 900。
2. **生成链路**：`src/features/group-chat/groupInitRunner.ts` 复用功能任务底座（取消、60s 空闲超时、流式 `onProgress`、`source:'aux'` 观测）；共同场景结构不合法时一次“只补结构”重试，二次失败抛可读错误；系统开场失败由 UI 重试或改选默认开场。**不写库**（保存由弹窗负责）。
3. **上下文注入**：`src/store/groupChatContext.ts` 在 `group.systemPrompt` 之后、世界书/成员卡之前注入共同场景块，声明「用户手写 System Prompt > 共同场景 > 角色卡场景」优先级；与 `scenarioInjectionMode` 正交；有画板位置关系时声明「位置/时间以画板为准」；字段为空时不注入。
4. **开场二选一**：`GroupInitPreambleModal` 四阶段（核对 → 共同场景预览 → 开场方式 → 系统开场预览）；系统开场以 `speakerKind:'narrator'`、`characterId:'__narrator__'` 消息插入（`insertNarrationMessage`），默认开场沿用现有 `GreetingPickerModal`，自动弹窗 path 未改。
5. **入口不打扰**：空状态主按钮「统一初始环境（AI）」、开场白弹窗内入口、设置面板入口；不自动弹、无 API 时按钮禁用并提示配置。
6. **设置面板**：新增「群聊前置设定」区块（失焦保存 / 清空即删字段 / AI 生成与重新生成 / 清除 toast / 成员快照变化提示 / 空会话「用系统开场开始」）。
