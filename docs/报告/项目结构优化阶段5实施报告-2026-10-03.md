### 2.1 修正的旧 UI 断言（清理报告登记的漂移）

清理最终报告登记「群聊画板入口改为启用开关后启动器首个等待即超时」。本阶段逐项修正：

1. **入口流程**：`创建空白` 按钮已移除 → 改为点击「群聊空间画板」后开启「启用空间画布」开关，开启即自动创建并绑定画板（mock 的 `setGroupEnabled` 幂等）；`青石城`（绑定已有世界）按钮已移除 → 新会话开启即自动绑定。
2. **AI 面板开合**：旧页面级「从当前设定生成」入口已移除 → 改为在 iframe 内点击「打开画板助手」，再按 `canInitialize` 显示「生成场景」。
3. **同步设置折叠**：`对话读取位置` 复选框与 `剧情同步策略` 下拉现收纳在默认折叠的「同步设置」`<details>` 内 → 断言前先展开。
4. **未明确项折叠**：`unresolved` 文案现位于折叠的「未明确项」详情内 → 断言前先展开。
5. **自动同步文案与入口**：单聊 auto 策略说明文案更新；`本轮位置已自动同步` 由持久提示改为 2s 瞬态、无持久「查看或撤销」入口 → 改为直接打开助手面板核对；auto 策略下低置信度建议不再提供手动「应用」→ 改为断言无手动入口。
6. **群聊阶段 3 mock 修正**：`applyGroupProposal` 覆盖原先用 mock 会话数组重置 store 会话，丢失 `spatialBoardEnabled` 导致「确认场景」后画板被判为关闭；改为在 store 会话上就地补 `spatialWorldId/spatialRuntimeId/spatialAiSessionId`。
7. **阶段 3 重开画板握手**：点「查看画板建议」重开画板后，等嵌入编辑器 `.react-flow__pane` 就绪再「预览地点创建」，避免保存确认握手超时。

## 4. check:boundaries（含负例）

新增 [scripts/check-boundaries.mjs](../../scripts/check-boundaries.mjs)，扫描 `src/`、`electron/`、`shared/`、`packages/spatial-core/src/`、`spatial-board/src/`（共 813 个源文件），解析静态/动态 import、命名 re-export、`require` 与相对路径（含 `@/` 别名）后按规则判定：

| 规则 | 内容 | 当前结果 |
|---|---|---|
| `shared-platform` | shared 纯核心不得依赖 Electron/React/Zustand/`@xyflow/react`、Node fs/child_process、PC/画板路径或 `@qingyu/*`；文本兜底仅匹配 `window.api`/`globalThis` | ✅ |
| `pc-no-board-internals` | PC（`src`+`electron`）不得引用 `spatial-board` 内部路径 | ✅ |
| `board-no-pc` | 画板不得反向依赖 PC `src/electron/shared/packages`，仅允许 `@qingyu/spatial-core` | ✅ |
| `core-purity` | `packages/spatial-core` 不得依赖宿主/shared/React/Electron/Zustand | ✅ |
| `features-cross` | `src/features/<a>` 不得导入其它 feature 内部实现（白名单：`chat→lorebook`、`group-chat→lorebook`，登记理由） | ✅ |
| `features-cycle` | feature 间相对导入不得成环（DFS 环检测） | ✅ |

- 正例：`check:boundaries OK — 扫描 813 个源文件`。
- 负例自检 `--self-test`：7 个注入文件样例 + 1 个循环图样例全部被拦截（`check:boundaries 负例自检通过（8 项）`）。
- 说明：传输层「仓储写实现」由 `check-write-bypass.mjs` 负责；本脚本聚焦依赖方向闭环，文本匹配仅作辅助（避免同名局部变量误报，例如 shared 中名为 `document` 的世界书对象）。

## 5. CI 门禁接入

`.github/workflows/ci.yml` 新增 `gates` job（递归检出子模块 → 安装 → 运行）：
- `pnpm check:gates` = 转发层残余（forwarders）+ 写路径（write-bypass）+ 边界（boundaries）+ 边界负例自检（boundaries:selftest）。
- `pnpm check:spatial-core`（core 纯度）。

`package.json` 补齐脚本：`check:contracts`、`check:write-bypass`、`check:boundaries`、`check:boundaries:selftest`、`check:gates`。

**契约检查（`check:contracts`）单列，暂不纳入硬门禁**：当前为已知红——同步信封 schema 的 `entityType` 枚举尚未包含 `memory_state`/`memory_fact`/`media_manifest`（这三类已存在于 Android 侧本地库表结构与 Bridge 的 media 通道规划）。修复需修改 `shared/contracts/schemas/sync-envelope.schema.json`（跨仓契约变更 + shared 提交与指针衔接），按方案 §6 移出结构批次，登记为阶段 6 跨仓收口候选。该脚本保留可单独运行，状态记入 `scripts/README.md`。
