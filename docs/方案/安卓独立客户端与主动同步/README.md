## 4. 看板维护规则

- 状态只用：未开始、进行中、阻断、待验收、已完成。
- “已完成”必须链接阶段报告；没有报告只能是“待验收”。
- 阻断项写明责任阶段和解除条件，不把设计问题留给后续 Agent 猜测。
- 契约、schema 或迁移发生变化时，必须列出兼容范围和 fixture 版本。
- 阶段 9 完成并经过观察期后，本目录与总方案移入 `方案/归档/`。
