# 阶段 5：内容管理功能对齐实施方案

> 状态：⚠️ 待处理  
> 前置：阶段 3、4。  
> 目标：补齐 Android 上独立创建和维护聊天所需的全部内容资产，并确保导入导出与 PC 兼容。

## 1. 任务拆分

### S5-01 角色管理

实现：

- 列表、搜索、排序、创建、复制、编辑、删除；
- 基础信息、描述、人格、场景、开场白、示例对话、系统提示；
- 多开场白、作者信息、扩展字段；
- 头像/聊天背景裁剪与替换；
- Character Card PNG V1/V2/V3 和 JSON 单个/批量导入；
- PNG/JSON/封面导出；
- 内嵌世界书提取与绑定。

Android PNG 元数据实现必须用共享 fixture 验证 chunk、编码和未知字段保留。导入文件走 Storage Access Framework，限制数量、单文件和总大小；媒体先解码验证再进入私有目录。

### S5-02 世界书

- canonical v2 完整编辑器；
- 条目启用、关键词、正则、key logic、位置、深度、顺序、权重、概率、递归与检索模式；
- native、SillyTavern World Info、CCv2/v3 character_book、lorebook_v3、Risu、Agnai、NovelAI 导入；
- 对支持格式导出并生成兼容性报告；
- `lorebook_mapping_template` 作为规范实体同步和备份；首版 Android 可只消费 PC/导入产生的模板，创建复杂映射模板可列入 P1，但不得阻断标准格式。模板中的路径表达式必须使用受限 DSL，不得携带可执行脚本。

格式检测、导入结果和导出再导入语义必须与 PC fixture 一致。

### S5-03 预设

- 内建/用户预设分区，创建、复制、编辑、删除、排序、启用；
- System Prompt、温度、topP、maxTokens、stop 等；
- 当前结构的生成规划、篇幅与推理字段；
- JSON 导入导出和 normalize；
- 删除被会话引用的预设时显示影响并安全解绑。

### S5-04 人设

- 创建、编辑、删除、默认人设、头像；
- 全局默认与会话覆盖；
- 删除引用处理；
- 宏与上下文注入和 PC 一致。

### S5-05 正则

- 创建、编辑、删除、启用、排序；
- 输入/输出作用域、flags、替换串和测试台；
- 对灾难性回溯设置执行超时或安全限制；
- 非 JavaScript/Java 共通的正则特性必须在导入时提示兼容性，不静默改变含义。

### S5-06 快捷回复

- 全局与角色级集合、分组、排序、编辑、启用；
- 文本插入与立即发送行为；
- 命令型回复只允许 Android 已支持命令，平台专用命令显示禁用原因；
- 导入导出兼容。

### S5-07 设置与用量

- PC 同步公开设置在 Android 具备等价入口；设备设置明确不参与同步。
- 用量记录以事件 ID 去重；统计按模型、角色、日期和成功/失败分类。
- 清空用量生成 `usage_clear_marker`，记录因果版本与清理范围；已知记录可批量 tombstone。自动保留上限不得静默删除同步记录，必须产生同样的清理语义，确保旧设备不会把已清理事件重新带回。

### S5-08 跨平台 Backup V3

定义 Backup V3：manifest、schema 版本、hash、counts、platform、excluded、canonical entities（包括映射模板与用量清理标记）、media。要求：

- PC 与 Android 可互相恢复非敏感数据；
- 默认排除 API Key、设备身份、spaceKey、令牌、向量索引和日志；
- ZIP 所有路径先验证再解压，拒绝绝对路径、盘符、反斜杠绕过、`.`/`..` 和符号链接；
- 导入先全包校验和预览，再 checkpoint 和原子应用；
- V2 仍可导入，V3 不要求旧版应用可读取。

## 2. UI 与可用性要求

- 编辑器自动保存必须写草稿区，不把每次键入都发布成同步变更；点击保存或离开确认后生成一个业务变更。
- 删除均显示影响范围；有引用的数据先解绑或阻止删除。
- 大型列表分页/搜索在数据库层执行。
- 所有导入显示成功、跳过、近似映射、失败和未知字段保留报告。
- 不因移动端屏幕小而隐藏关键高级字段，可放入折叠高级区。

## 3. 测试矩阵

- 每种外部格式使用阶段 0 fixture 做 PC 导入 → Android 导出 → PC 再导入，以及反向流程。
- 角色/世界书/预设未知字段 round-trip 不丢失。
- 删除有引用资产的所有分支均有测试。
- 正则兼容差异有固定样例和明确错误。
- Backup V3 覆盖篡改 hash、缺条目、重复条目、ZIP bomb 上限、路径穿越、磁盘满和恢复回滚。
- 500 角色、100 世界书/每书 5k 条、1k 预设等压力数据下列表可用。

## 4. 完成定义

用户可以只用 Android 建立和维护完整聊天资产，不需要回 PC 补字段；P0 格式跨端往返无语义损失；所有写入进入 Repository 和 change journal。
