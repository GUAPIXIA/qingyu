# 阶段 6：群聊与平台扩展对齐实施方案

> 状态：⚠️ 待处理  
> 前置：阶段 4、5。  
> 目标：完成群聊、媒体、TTS、向量、图片和 MCP 等能力的平台等价，使“完整功能”不只停留在单聊和文本管理。

## 1. 任务拆分

### S6-01 群聊核心

Kotlin 实现并与 PC fixture 对齐：

- 群组创建、编辑、删除、成员增删和排序；
- mention、polling、free 三种发言模式；
- 群会话、消息归属、旁白与角色身份；
- 单成员/多成员上下文、预设/世界书/人设绑定；
- 群消息编辑、删除、翻译、TTS、续写和导出；
- 群记忆、CAS 和历史失效；
- 生成中断与部分角色失败的终局。

群聊调度器是领域状态机，不得放在 Compose coroutine 或 UI 循环里。

### S6-02 附件与识图

- 使用 SAF 选择图片，读取时校验 MIME、magic bytes、尺寸和大小。
- 生成缩略图，原图进入内容寻址私有 blob store。
- 模型请求按 provider 能力构造图像输入；不支持时在发送前阻断。
- EXIF 默认剥离；如保留方向，解码后重编码。
- 同步只传加密 blob，不传 `content://`、绝对路径或 PC `/static` URL。

### S6-03 TTS

- Android 系统 TTS：语言/音色列表、播放/暂停/停止、队列和音频焦点。
- 网络 TTS：只实现当前公开供应商协议，凭据来自本地 secret store。
- PC Windows-only voice 配置同步为 public metadata 时，在 Android 显示“不适用”，不尝试按名字猜测音色。
- TTS 音频默认缓存，不作为用户主数据同步；用户显式保存的音频才进入 media manifest。

### S6-04 生图与 ComfyUI

- OpenAI Images、SD WebUI、ComfyUI 网络端点按 PC 当前有效能力实现。
- ComfyUI 工作流分析/参数覆盖使用共享 fixture；Android 不扫描 PC 本地工作流目录。
- `localhost` 配置迁移时提示其在手机上指向本机，要求填写可访问地址。
- 生成结果下载、校验、保存为 media entity，可选择绑定消息或角色。

如果届时 PC 已正式移除某条生图入口，以阶段 0 能力矩阵和最新产品决策为准，不复活已删除功能。

### S6-05 Embedding 与语义检索

分级实现：

1. 远程 OpenAI-compatible/Ollama embedding；
2. 支持设备上的本地移动端模型；
3. 资源不足时关键词/词法降级。

索引按 `model fingerprint + entity revision + chunk strategy version` 失效。索引和模型包不参与同步，目标端根据 lorebook/memory 数据重建。下载包必须有签名/hash、断点续传、空间预检和卸载影响提示。

### S6-06 MCP 平台策略

- Android 支持远程 Streamable HTTP/SSE MCP，实施与 PC 相同的工具清单、参数 schema、权限确认和超时。
- stdio MCP 保留配置可见性但标记 `platformSupport=pc_only`，Android 不尝试启动本地进程。
- 工具调用只能由当前生成任务发起，权限默认拒绝，敏感结果不写普通日志。
- 同步 `mcp_public_config` 只含名称、URL/transport、启用状态和权限模板；认证头/环境变量不上传。

### S6-07 公告、更新与诊断

- 公告与 Android 版本检查保留。
- 应用更新按发布渠道实现下载、hash 校验和系统安装确认；不得静默安装。
- 诊断包包含版本、能力、数据库 schema、同步摘要和脱敏错误，不含正文和秘密。

## 2. 平台等价验收表

每项 PC 能力必须得到以下之一：

- `same`：相同协议和结果；
- `equivalent`：Android 原生替代，用户目标一致；
- `pc_only_confirmed`：阶段 0 已签字，UI 明确告知。

执行 Agent不得自行用“移动端不方便”把功能降为不支持。

## 3. 测试

- 群聊三模式对同一 fixture 产生相同发言计划与上下文。
- 生成中删除成员、切换模式、取消、部分失败不会写错角色归属。
- 恶意图片、伪 MIME、超大像素、损坏音频、重定向和 SSRF 边界被拦截。
- embedding 更换模型后旧索引不被复用；无 embedding 时结果可解释。
- MCP 工具越权、参数不合法、超时、断线和提示注入内容不会绕过权限。
- 真机验证音频焦点、蓝牙/耳机、后台恢复、低存储和 Android 权限撤销。

## 4. 完成定义

阶段 0 P1 能力矩阵全部达到 same/equivalent；阶段 0 明确纳入本轮的 P2 项必须完成，其余 P2 项有签字确认的排期。关闭 PC 后 Android 的群聊、媒体和扩展能力独立可用，降级均可见且不会损坏数据。
