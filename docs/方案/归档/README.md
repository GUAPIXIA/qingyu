## 归档规则

1. **`方案/` 落地后一律归档：** 状态到达「✅ 已完成」且验证通过后，移动到本目录；`方案/` 只保留「待实施 / 运行期观察 / 待处理」等未收口文档。
2. **不再直接删除。** 过时或被取代同样移入本目录。
3. **文件名日期（2026-09-13 起）：** 新建文档建议带日期 `…-YYYY-MM-DD.md`；**存量文档不追溯改名**。
4. 移动时同步登记：本页清单 + [`../../README.md`](../../README.md) 对应小节。
5. 文件名冲突时追加移除日期：`原文件名-YYYY-MM-DD.md`。
6. 归档文件**不再更新内容**；文内路径/行号可能失效，阅读以仓库当前状态为准。
7. 需要恢复时移回 `方案/`，并从本页清单删除该行。
