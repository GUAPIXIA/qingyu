# ADR-005: 同步必须手动触发；LAN 由 Android 发起一次性会话

- 状态：已接受
- 日期：2026-09-16
- 决策阶段：阶段 0

## 背景

总方案明确：取消业务数据实时同步；禁止启动时/进页/后台定时/网络变化自动同步。局域网若要求 Android 常驻 HTTP 服务，将受后台限制、耗电与权限约束影响。

## 选择

- 仅当用户进入同步中心并确认计划后，才执行上传/下载/合并。
- LAN：Android 作为客户端主动连接 PC Bridge 暴露的 `/sync/v1`；PC 侧“允许本次同步”签发短时一次性会话（二维码）。
- 可选“提醒我有未同步更改”只读本地提示，不发网络请求。
- 服务器模式同样仅在用户确认后 push/pull。

## 否决方案

1. **后台周期同步/FCM 静默合并**：否决。违反主动同步边界与计费/后台限制风险。
2. **Android 常驻 HTTP 服务由 PC 拉取**：否决（首版）。系统后台限制使方案脆弱。

## 后果

- 多端长期分叉是预期状态；冲突与预览是一等能力。
- LAN 二维码/一次性密钥与 PC 确认页成为安全边界（ADR-010）。

## 重新评估条件

- 产品要求接近实时协同，且接受新的威胁模型与电量/权限成本时另开 ADR。
