# ADR-007: 首个独立客户端单轨切换；不保留旧伴侣运行模式

- 状态：已接受
- 日期：2026-09-16
- 决策阶段：阶段 0

## 背景

旧 Android 依赖 PC Bridge/Relay RPC。若新包隐藏 `companionLegacyEnabled` 或保留回退通道，则测试矩阵、安全审计与用户可理解性都会劣化，且旧路径永不退出。

## 选择

- 新版只运行独立客户端架构。
- 不提供旧伴侣模式、隐藏开关、旧远程会话页或旧 Relay RPC 回退。
- 旧链路删除按阶段 9 清单一次性落地；此前不得以“紧急回退”在新安装包启用。
- 迁移窗口若需 legacy Relay，仅允许隔离冻结部署，不得写入新同步存储、不得被新客户端调用。

## 否决方案

1. **双模式长期共存**：否决。能力矩阵与安全面翻倍。
2. **运行时功能开关回退旧模式**：否决。违反“不以隐藏开关保留旧运行时”。

## 后果

- 发布门禁含迁移演练与旧路径清零证据（总方案 §9.2）。
- 迁移失败只能回滚升级前快照，不能进旧伴侣模式。

## 重新评估条件

- 无。与“独立客户端”目标直接冲突；若产品改回伴侣模式须废止本重构阶段计划。
