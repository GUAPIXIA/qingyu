> 日期：2026-09-26  
> 状态：**本地已完成**（subtree split 保历史；远程 GitHub 仓库待用户创建并推送）

## 1. 目标布局

```text
D:\Code\qingyu\              # PC 仓（Electron + React + relay-server + docs）
├── .gitmodules
├── shared/                  # 子模块 → qingyu-shared
└── android/                 # 子模块 → qingyu-android

D:\Code\qingyu-shared\       # 契约 / chat-core / golden fixtures（第三仓）
D:\Code\qingyu-android\      # Android 工程（独立仓）
```

| 仓库 | 内容 | 本地路径 | 拆分方式 |
|---|---|---|---|
| **PC** | `src/` `electron/` `relay-server/` `docs/` `scripts/` `tools/` | `D:\Code\qingyu` | 原 monorepo 去掉 shared/android 内联 |
| **Shared** | `shared/`：contracts、chat-core、sync-core/crypto、fixtures | `D:\Code\qingyu-shared` | `git subtree split --prefix=shared` |
| **Android** | `android/` 完整 Gradle 工程 | `D:\Code\qingyu-android` | `git subtree split --prefix=android` |

---

## 2. 为何 shared 独立成仓

- 跨语言 **golden fixture** 是 TS（oracle）↔ Kotlin 的一致性锁。
- Android 测试按 `../shared/fixtures/cross-platform/...` 读同一份 fixture。
- 契约变更（schema / envelope / chat-core）必须两端同步，独立仓 + 子模块钉版本可避免漂移。

## 3. 日常用法

### 3.1 克隆

```powershell
git clone <pc-remote> qingyu
cd qingyu
# 本地开发期（远程仓库未建好时）：
git config protocol.file.allow always
git submodule set-url shared  D:/Code/qingyu-shared
git submodule set-url android D:/Code/qingyu-android
git submodule update --init --recursive

# 远程建好后（推荐最终形态）：
git clone https://github.com/GUAPIXIA/qingyu.git
git clone https://github.com/GUAPIXIA/qingyu-shared.git
git clone https://github.com/GUAPIXIA/qingyu-android.git
# .gitmodules 建议改为：
#   url = ../qingyu-shared.git
#   url = ../qingyu-android.git
git submodule update --init --recursive
```

### 3.2 改契约 / fixture

```powershell
cd D:\Code\qingyu-shared
# 改 shared/chat-core 或 fixtures ...
# 生成 fixture（TS oracle）：
cd D:\Code\qingyu
$env:CHAT_CORE_UPDATE_FIXTURES="1"
pnpm exec vitest run shared/__tests__/chatCoreGolden.test.ts
# 提交 shared 仓，并在 PC/Android 仓 bump 子模块指针
```

### 3.3 Android 跑门禁

```powershell
cd D:\Code\qingyu\android   # 或 D:\Code\qingyu-android
$env:GRADLE_USER_HOME="D:\Code\gradle-home"
.\gradlew.bat :app:testDebugUnitTest --rerun
```

fixture 路径解析兼容 `../shared`（与 PC 仓同级时）及仓库内 `shared/`。

## 5. 注意事项

1. **`protocol.file.allow`**：本地 file:// 子模块 clone 需 `git -c protocol.file.allow=always` 或仓库级 `git config protocol.file.allow always`（Git 出于安全默认拒绝）。
2. **备份目录**：`shared-inline-backup/`、`android-inline-backup/` 为拆分时的工作区备份，确认无误后可删。
3. **不要**把 `s9-*.txt` 等临时日志提交进仓。
4. 原 remote `standalone-android` → `D:/Code/qingyu/android` 可改为指向 `D:/Code/qingyu-android`。
5. 推送到 GitHub 前需用户创建 `qingyu-shared`、`qingyu-android` 仓库；**本工具未执行 push**。

## 6. 回滚

若需回到 monorepo：

```powershell
# 1. 去掉子模块
git rm --cached shared android
rm .gitmodules
# 2. 从备份或 subtree 分支恢复目录
# 3. git checkout split-shared -- shared 概念同理
```

或直接使用拆分前 monorepo 历史（main 仍含完整内联历史至 `949b347` 之前）。
