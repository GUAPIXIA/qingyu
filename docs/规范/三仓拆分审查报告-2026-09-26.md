## 5. 遗留与建议

### 5.1 待用户操作（推送）

```powershell
cd D:\Code\qingyu-android

git push -u origin main

cd D:\Code\qingyu
git push origin main
# 子模块相对 URL ../qingyu-* 在 GitHub 同账号/同 org 下可解析
```

### 5.2 可清理（确认无误后）

- `D:\Code\qingyu\shared-inline-backup\`（278 文件，已核对一致）
- `D:\Code\qingyu\android-inline-backup\`
- 根目录 `s9-*.txt`
- 拆分临时分支 `split-shared` / `split-android`（qingyu 仓内）

### 5.3 使用注意

1. **file 协议**：本地子模块 clone 需 `git -c protocol.file.allow=always` 或仓库 `git config protocol.file.allow always`（Git 默认拒绝）。
2. **改契约**：在 `qingyu-shared` 提交 → PC/Android 各自 `git add shared` bump 指针。
3. **Android 独立开发**：克隆 `qingyu-android` 后 `git submodule update --init` 拉 fixture。
4. PC 的 `protocol.file.allow=always` 已写在本地 config（可移植配置用相对 URL + 远程仓）。
