| 项目 | 值 |
|---|---|
| ADB 调试端口 | `5557`（主）、`16416` |
| ADB 连接地址 | `127.0.0.1:5557` 与 `127.0.0.1:16416` |
| 电脑 DNS | 198.18.0.2 |
| 电脑出口 IP | 183.197.251.33 |
| 防火墙 | 关闭（利于 adb 连接） |

**已验证**：两个端口均能通过 `adb connect 127.0.0.1:5557 / 16416` 连接，设备序列号即为上述地址，Android 版本 15，屏幕 1440x2560。

### ADB 使用备忘

- ADB 路径：`C:\Users\Administrator\AppData\Local\Android\Sdk\platform-tools\adb.exe`
- 连接命令：
  ```bash
  adb connect 127.0.0.1:5557
  adb connect 127.0.0.1:16416
  ```
- 常用操作（以 `-s 127.0.0.1:5557` 指定设备）：
  ```bash
  adb -s 127.0.0.1:5557 install app.apk
  adb -s 127.0.0.1:5557 shell am start -n 包名/Activity
  adb -s 127.0.0.1:5557 shell screencap -p /sdcard/s.png && adb -s 127.0.0.1:5557 pull /sdcard/s.png
  adb -s 127.0.0.1:5557 logcat
  ```
- 若连接断开，先 `adb kill-server` 再重新 connect。

## 6. 注意事项 / 已知限制

1. **Root 关闭**：需要 root 的操作（如修改系统分区）不可用。
2. **模拟器磁盘显示 0 GB/0 GB**：该信息异常，判断磁盘空间以电脑系统盘为准。
3. **可用内存 0.6 GB**：模拟器占用 4 GB 后系统剩余较少，运行大型构建/多模拟器时注意内存。
4. 防火墙关闭，网络直连；如遇网络异常先查 DNS（198.18.0.2）。
5. 本机同时装有 Android SDK（路径见上），可配合 gradle 构建 APK。
